How to connect Design Wallet MCP

How to connect in Claude?

Works on every Claude plan. Free plans can add one custom connector. Once added, it works in the mobile app too.

  1. Open Claude on the web or desktop and go to Customize → Connectors.
  2. Click Add custom connector.
  3. Name it Design Wallet and paste the connector URL. There is nothing to sign in to.
  4. Click Add, then switch Design Wallet on from the tools menu in any chat.
  5. Ask: “Find me free icon sets for Figma in Design Wallet.”

How to connect in ChatGPT?

OpenAI offers custom MCP servers on ChatGPT Business, Enterprise and Edu.

  1. In ChatGPT on the web, open Settings → Plugins (Apps & Connectors on some plans) and add a custom MCP server.
  2. For the icon, use the Design Wallet logo (256 × 256 PNG, under 10 KB). Name it Design Wallet, and for the description you can paste: 
    Search Design Wallet's hand-picked catalogue of 430+ design tools, plus designer salaries, articles and book picks.
  3. Paste the connector URL. Under Authentication, change OAuth to No authentication. Design Wallet has nothing to sign in to.
  4. Tick “I understand and want to continue”, then pick Design Wallet in a new chat. ChatGPT shows that risk notice for every custom server; Design Wallet is read-only and can only search our catalogue, never your chats, files or account.
  5. Ask: “Find me free icon sets for Figma in Design Wallet.”

How to connect in Cursor?

Works in Cursor’s Agent chat.

  1. Open Cursor Settings → MCP and add a new MCP server. This opens mcp.json.
  2. Add Design Wallet and save: 
    {
  "mcpServers": {
    "design-wallet": { "url": "https://mcp.designwallet.in" }
  }
}
  3. In Agent chat, ask: “Find me free icon sets for Figma in Design Wallet.”

How to connect in Claude Code?

Needs Claude Code installed and signed in.

  1. Open your terminal and run: 
    claude mcp add --transport http design-wallet https://mcp.designwallet.in
  2. Start Claude Code and type /mcp to check Design Wallet is connected.
  3. Ask: “Find me an icon set in Design Wallet.”

How to connect in Codex?

The Codex app, CLI and IDE extension share one setup, so adding it once is enough.

  1. In the Codex app, open Settings → MCP servers → Add server.
  2. Name it design-wallet, choose Streamable HTTP and paste the connector URL.
  3. Save, then click Restart.
  4. Prefer the terminal? One command does the same: 
    codex mcp add design-wallet --url https://mcp.designwallet.in

How to connect in VS Code?

Use it from Copilot Chat in Agent mode.

  1. Open the Command Palette (⇧⌘P / Ctrl+Shift+P) and run MCP: Add Server.
  2. Choose HTTP, paste the connector URL and name it design-wallet.
  3. Or add it to .vscode/mcp.json yourself: 
    {
  "servers": {
    "design-wallet": { "type": "http", "url": "https://mcp.designwallet.in" }
  }
}
  4. In Copilot Chat (Agent mode), ask: “Find me free icon sets in Design Wallet.”

How to connect in Gemini?

For Gemini CLI. Add -s user to use Design Wallet in every project.

  1. Run this in your terminal: 
    gemini mcp add --transport http design-wallet https://mcp.designwallet.in
  2. Or add it to ~/.gemini/settings.json: 
    {
  "mcpServers": {
    "design-wallet": { "httpUrl": "https://mcp.designwallet.in" }
  }
}
  3. Restart Gemini CLI, type /mcp to check, then ask: “Find me free icon sets in Design Wallet.”

FAQs

Where does Design Wallet MCP work?

Claude on the web, desktop and mobile, Claude Code, ChatGPT (Business, Enterprise and Edu), Cursor, Codex, VS Code and Gemini CLI. Any app that supports remote MCP servers over HTTP can use it.

Is it free?

Yes. No signup, no account and no API key. Your AI app’s own plan and usage limits still apply.

Do I need a paid Claude plan?

No. Free Claude plans can add one custom connector, which is all Design Wallet needs. Paid plans can add more.

Why should my prompt say “in Design Wallet”?

Claude chooses which connector to use. Saying “in Design Wallet” tells it to search our catalogue instead of answering from its own knowledge.

What can I ask it?

Find tools by what you need, browse all 40 categories, compare 2 to 5 tools, check designer salaries in India and around the world, find Design Wallet articles and get book recommendations.

Will Claude suggest tools that aren’t on Design Wallet?

No. Answers come only from Design Wallet’s hand-picked catalogue. If nothing fits, Claude says so instead of making one up.

How fresh is the catalogue?

It’s live. When we add or update a tool on Design Wallet, the connector has it within minutes.

How is my data handled?

We keep an anonymous log of what’s searched and what was found, so we know which tools to add. We never record who asked, and we never see your conversation with the AI app.

Is it listed in Claude’s official directory?

Not yet. For now, add it as a custom connector using the connector URL above.

My tool isn’t listed. How do I get it in?

Head to List your tool on Design Wallet and book a call. Searches that find nothing also tell us what designers are missing.
